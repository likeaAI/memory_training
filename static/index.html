📖 Gemma 4 / Qwen 로컬 파인튜닝 퀵 가이드

내보낸 gemma4_memory_finetune.jsonl 파일을 사용하여, Google Colab(무료 T4 GPU) 또는 로컬 PC(VRAM 8GB)에서 Unsloth로 초고속 QLoRA 파인튜닝을 진행할 수 있습니다.

# 1. Unsloth 설치
pip install "unsloth[colab-new] @ git+https://github.com/unslothai/unsloth.git"

# 2. Gemma 4 E4B 베이스 로드 & LoRA 적용 (8GB VRAM 최적화)
from unsloth import FastLanguageModel, FastVisionModel
model, tokenizer = FastVisionModel.from_pretrained(
  model_name="unsloth/gemma-4-E4B-it",
  max_seq_length=512, load_in_4bit=True
)
model = FastVisionModel.get_peft_model(model, r=16, lora_alpha=16, finetune_vision_layers=False)

# 3. 내보낸 JSONL 데이터셋 로드 및 학습 (15분 소요)
from datasets import load_dataset
from trl import SFTTrainer
dataset = load_dataset("json", data_files="gemma4_memory_finetune.jsonl")
trainer = SFTTrainer(model=model, tokenizer=tokenizer, train_dataset=dataset["train"], dataset_text_field="output")
trainer.train()

# 4. GGUF 변환 후 Ollama 등록
model.save_pretrained_gguf("my_memory_gemma4", tokenizer, quantization_method="q4_k_m")
